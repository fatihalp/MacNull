# MacNull

MacNull frees up disk space by finding old build files, developer caches, and other junk. Review what it finds before moving items to the Trash.

## Download and install

Requires a Mac with Apple silicon and macOS 14 (Sonoma) or later.

1. Open the [latest MacNull release](https://github.com/fatihalp/MacNull/releases/latest).
2. Under **Assets**, download the file ending in `.dmg`.
3. Open the DMG from **Downloads** and drag **MacNull** into **Applications**.
4. Open **MacNull** from **Applications**.

## Build from source

With Swift 6 installed, run `swift build`. Use `swift run MacClean` to open the app or `swift run MacClean help` for CLI commands.
